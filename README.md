# Mach-Zehnder-Analog-Amplifier
Analog front-end differential amplifier for integrated photonic Mach-Zehnder interferometers. A Mach-Zehnder Interferometer is a photonic device used to determine the relative phase shift between two collimated light beams split from a single light source. For the light detection 2 transversal photodetectors were used, developed in the I3N laboratory at Politecnico di Milano

The main goal of the project was to measure the optic power and to eliminate dark current contribution
